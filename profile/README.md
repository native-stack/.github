### 🏗️ The Ecosystem
A curated set of zero-dependency, high-performance primitives built for the modern Node.js 24+ era. We bypass the "dependency bloat" to talk directly to the platform.

| Library | Version | Primitive | Description |

### 📜 The Manifesto
Every project under the Native Stack umbrella is governed by three non-negotiable engineering principles:

* **Zero-Dependency:** 100% auditable codebases. No transitive dependencies. No supply-chain risk.
* **Platform Native:** We leverage the Node.js standard library (Built on `node:sqlite`, `node:stream`, and `node:test`).
* **Architect-First:** Designed for high-concurrency, long-running agentic tasks where durability is paramount.
